# 🌙 لونا تشان — Luna Chan

مكتبة سحب وتحميل الروايات بواجهة كيوت ومحترمة للخصوصية.

## المزايا

- **يحمّل من كل المواقع**: محرّك سحب عام (HTML heuristics + JSON-LD + OG) يعمل مع أي موقع روايات،
  مع محرّكات مخصّصة دقيقة للمنصّات الشائعة (روابط `story/…`, `ar/novels/…/chapters/…`, `read.php?post_id=…`).
- **يجلب كل ما هو مطلوب فقط**: العنوان، الغلاف الأصلي، الوصف/الملخص/النبذة، عناوين الفصول،
  نص كل فصل، والصور الموجودة داخل الفصول — ويستبعد الإعلانات والقوائم والتعليقات وأي شيء غير مرغوب.
- **لا يخترع أي نص**: إذا لم يستطع المصدر تسليم فصل، يُذكر الفصل باسمه فقط في قسم ملاحظات الاستيراد.
- **معاينة قبل التحميل**: قارئ داخل الموقع مع الصور، ثم تختارين الصيغة.
- **صيغ متعددة**: EPUB · PDF · HTML · TXT · Markdown · DOCX · FB2 · JSON.
- **الغلاف لا يتغيّر**: يُحفظ بنفس بايته ويُضاف كما هو في جميع الصيغ.
- **لوحة الأوزان**: عدد الفصول/الكلمات/الصور، زمن القراءة، وزن كل صيغة، ووزن كل فصل على حِدة.
- **بدون تسجيل دخول** وبدون إعلانات.
- **ثلاث لغات**: العربية (افتراضي RTL) · Français · English، مع ثلاث لوحات ألوان (بنفسجي ذهبي، وردي، نعناعي).
- **تفاعل كيوت**: قلوب وشرارات وتقدّم متحرّك عند إضافة الرابط.

## التقنية

Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · PostgreSQL + Drizzle ORM · cheerio · pdf-lib (+Amiri للعربية) · JSZip.

## تشغيل محلي

```bash
npm install
cp .env .env.local            # ثم ضعي DATABASE_URL
npx drizzle-kit push          # إنشاء الجداول
npm run dev                   # http://localhost:3000
```

## نسخة PHP المستقلّة (للاستضافات المجانية مثل aeonfree)

- `index.php` + مجلد `php/` = نسخة كاملة من لونا تشان تعمل على PHP فقط: نفس الواجهة (عربي/فرنسي/إنجليزي)،
  السحب من كل المواقع، المعاينة، لوحة الأوزان، والتحميل بكل الصيغ — **بدون Node وبدون قاعدة بيانات**.
- التخزين في مجلد `data/` (يُنشأ ويُحمى تلقائيًا)، وخط PDF من `assets/fonts/`.
- الفحص: `index.php?r=health` و `index.php?r=diag`.
